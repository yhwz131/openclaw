# 开场情景剧｜HR的一天（第二版）

- 时长：约 2 分 40 秒
- 位置：团队介绍之后、项目首页之前
- 人物：HR 小周（戴乐奇眼镜，队员出演，不用真名）
- 画面来源：眼镜第一人称 + 电脑录屏。眼镜只负责和小慧说话；电脑上的结果是系统真实跑出来的，不改、不摆拍
- 主线：小周戴着眼镜把一天的事说给小慧，五个模块各接一件，每件都停在不该 AI 替人做的地方

## 录制方式

1. 小周用乐奇「龙虾助手」直接对小慧说话，一次只说一件事，等它答完再说下一件。
2. 眼镜画面保留小周的话和小慧的回话（字幕补上，现场音响听不清时评委也能看懂）。
3. 同时录电脑上的返回结果。剪辑时眼镜和电脑对切，同一件事的问句和结果留在一起。
4. 等待过程剪掉。函数、命令、内部字段不进片子。

### 2｜同一个入口，两件事（0:12—0:32）

**画面**
眼镜里连续两句，中间不摘眼镜、不换入口。电脑录屏跟着切结果。

1. 小周："员工1的入职办到哪一步了？"
   小慧回报当前卡在哪个节点、还缺什么。
2. 小周："再从人才库里找几位和员工1背景相近的人。"
   小慧回报候选人、相似度和推荐依据。

**字幕**
一个入口，两件事，分别交给入职和招聘

**录制注意**
两句分开说。不要一句里塞两件事，总控不会拆开。

### 3｜招聘：简历上没有的数字（0:32—0:52）

**画面**
小周："帮我看一下这份候选人的评分。"
电脑上评分里一句标红："具备 58 万笔/秒保障经验"。
小慧："简历上没有 58 万。原简历是大促峰值 12.8 万 TPS，我已经改回去了。约不约面试，你定。"
录屏闪过修正前后的快照。

**字幕**
简历里没有的数字，写不进评分

**录制注意**
58 万是开发中抓到的真实错误样本，拍回核脚本对它真实跑出的结果。不拍成模型当场写错，不出现函数代码。

### 7｜行政：有出处才答，没权限就拒（1:48—2:18）

**画面**
三小段，都从小周嘴里问出去。

1. 小周："员工问，年假到年底没休完怎么办？"
   小慧按制度原文回答，结尾说出文件名。电脑上回答末尾能看见出处。
2. 小周："有人想查员工1的合同薪资，他不是人事。"
   小慧："这个人没有权限，我拒绝了，薪资没有查出来。"电脑上是拒绝结果，不是一份工资。
3. 小周："九月的 HR 月报呢？"
   电脑打开月报。小慧报两三个数，并补一句："四十五天内离职率还在统计，缺的数我不补。"

**字幕**
回答带出处；不该看的查不到；月报的数能对回表

## 五个模块各拍什么

| 模块 | 片子里的一件事 | 留给现场技能段的 |
|---|---|---|
| 招聘 | 人才库检索；58 万改回 12.8 万 | 手写数字回核、脱敏脚本 |
| 入职 | 进度查询；合同停住、人批完又停在账号 | 两道门怎么走 |
| 培训 | 只出点名的评估表，并标明讲师要审 | 生成和自检过程 |
| 绩效 | 360 看板，没有等级 | 缺自评就拒绝汇总 |
| 行政 | 制度带来源、越权查薪资被拒、月报缺数不补 | 身份闸和计算过程 |

## 这支片子不做的事

- 不演五个模块自动串成流水线。每件事都是小周单独说出来的
- 不拍「眼镜拍照就出评分」「眼镜录音就出面试纪要」。乐奇在这支片子里只用来和小慧说话
- 不念政策文件和设计哲学，留给后面的问题页、亮点页
- 不出现代码。代码留给技能段现场写
- 不出现真实姓名、学校、公司名

## 需要你们确认

1. 小周由谁出演。其余队员是否出镜
2. 龙虾助手的回话是镜片字幕、耳机，还是两边都有。字幕我们另外补，不依赖现场音响
3. 员工1、员工2 的演示状态录完要还原，不影响技能段现场
