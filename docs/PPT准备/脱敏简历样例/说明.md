# 脱敏简历样例（赛场可展示）

四份均为虚构夹具，可直接投屏或交给解析。未放入招聘 `inbox/`，不会进入现有人才库，也不改员工1 的 12.8 万 TPS 演示数据。

本目录没有赛项规程原件。脱敏口径取自两处已经在用的规则：

- 赛场材料：不用真实姓名、学校、企业、身份证号、完整手机号和邮箱；单位和学校用代号。
- 评分输入（`candidate-profile-schema.md` §9）：不写年龄或出生年月、性别、婚育、户籍籍贯、民族、健康或残疾、院校层次（含 985/211、第一学历）、政治面貌。

保留的是岗位判断要用的内容：工作年限、毕业年份、专业与学历、项目数字、技能。工作年限不是年龄。
