## 1. 删除敏感字段

【打开 `test-fixtures/demo-lifecycle/planted-sensitive-员工1-full.json`】

我们不叮嘱模型别用，而是在进评分之前，用脚本把它们从数据里删掉。

bash scripts/recruitment-run.sh node skills/filtering-sensitive-fields/scripts/filter_sensitive.js \
  test-fixtures/demo-lifecycle/planted-sensitive-员工1-full.json \

【指终端】删除 31 项，里面包括年龄、性别，还有嵌在教育经历里的院校层次。自检剩余 0，退出码 0。

【打开 `scoring/demo-脱敏后-员工1.json`】

这是删完的结果。交给评分模型的是这份副本，原始画像还在，HR 仍然可以查看。

## 3. 写回比对，拦住并改回去

现在把比对写回去。找得到整段，算通过；只找到数字、单位对不上，交给模型看；连数字都没有，就是存疑。比对对象只有原简历，不接收岗位说明。

【把 `verifyInResume` 改回下面这样，保存】

```javascript
function verifyInResume(token, resumeNorm) {
  const tokenNorm = norm(token);
  if (resumeNorm.includes(tokenNorm)) return true;
  const numMatch = tokenNorm.match(/\d+(?:\.\d+)?/);
  if (numMatch && resumeNorm.includes(numMatch[0])) return null;
  return false;
}
```

【运行同一条命令，输出换成新文件】

```bash
bash scripts/recruitment-run.sh node skills/auditing-numbers/scripts/audit_numbers.js \
  scoring/results/ranking-员工1-后端开发.json \
  inbox/resume-tech-员工1-后端开发.md \
  scoring/demo-回核后-员工1.json
```

【先指“存疑 11 个”】23 个数字里，11 个对不上原简历。58 万在其中，这一步已经拦住了。

【若出现“已修正”，并打印“修正后评分结果已写出”】

存疑的数字再交给模型判断是不是编的。判成编造的，改回原简历的值，并留下修改前、修改后。

【打开 `scoring/demo-回核后-员工1.json`，指抗压能力】

抗压能力已经从 58 万笔每秒改成 12.8 万 TPS。原来的错误评分没有被覆盖，改回的结果在这个新文件里。

【若打印“数字回核失败”，退出码是 1】

比对已经拦住了 11 个存疑数字。后面的模型判定这次没有返回合法结果，脚本停在这里，没有把失败当成通过，也没有写出新文件。

【改打开 `scoring/results/ranking-员工1-后端开发.audited.json`】

这是事先跑完留好的修正结果。同一栏已经是 12.8 万 TPS。当场判定没有完成，我用这份留好的结果说明改回之后是什么样。

## 4. 渲染候选人画像

评分是给程序看的，HR 看的是画像。这一步只把刚才那份回核后的评分画成网页，不重新评分，不调用模型，大约 1 秒。

【判定成功时，用刚写出的文件运行】

```bash
bash scripts/recruitment-run.sh python3 skills/generating-candidate-profiles/scripts/generate_profile.py \
  scoring/demo-回核后-员工1.json \
  员工1 profile/output/profile-员工1-回核后.html
```

【判定失败、没有这份新文件时，改用留好的修正结果】

```bash
bash scripts/recruitment-run.sh python3 skills/generating-candidate-profiles/scripts/generate_profile.py \
  scoring/results/ranking-员工1-后端开发.audited.json \
  员工1 profile/output/profile-员工1-回核后.html
```

【浏览器打开 `profile/output/profile-员工1-回核后.html`】

请看三处：八个维度的雷达图；页面上没有年龄、性别；评级只是建议，不定录用。58 万改成 12.8 万那句话在评分文件里，画像不放这段评语。

敏感字段删到 0，评分模型看不到。没有比对，58 万会写进结果文件；补上比对，对不上的数字被拦住，编造的改回原简历。约不约面、录不录用，由 HR 决定。
