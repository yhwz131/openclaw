## ① 启动入职：部门没办完，不进门（约 40 秒）

【HCM 前端点“新建候选人”：姓名“新员工”，拼音填本场拼音，岗位后端工程师，薪资 32K】

【对话窗口发送】“为新员工启动入职，岗位后端工程师，薪资32K”

它没有进审批门，而是报了卡点：哪几个部门节点还没完成，建议催哪个部门。部门线没办完，HR 这条线就不审；它不替部门填，只把卡点告诉人。

【终端运行】

```bash
bash demo/show-workflow.sh <拼音>
```

应显示“还没有流程记录”：流程没有进门，后面一步都没走。

【如果它反问拼音】回复本场拼音即可，不算失败。

## 失败时怎么收场

【第 ① 步它直接进了审批门】说明 HCM 里部门节点已经是“已完成”，多半是队友提前点了。如实说明，跳到第 ② 步的核对。

【第 ⑤ 步没有挂提醒】多半是 Buddy 节点没办完。它会报卡点，这本身就是规则在起作用：“部门没办完，就不开跟进。”请队友办结 Buddy 后，再发一次“继续入职”。

【对话窗口无响应】改在终端发同一句话：

```bash
openclaw agent --agent onboarding --session-id onb-<拼音> -m "部门都办完了，继续入职"
```

整场用同一个 `--session-id`。

【网络异常】播放备用录屏，并说明是备用录屏。
