# 培训子 Agent“小慧”PPT 大纲

> 共 4 页：封面 1 页 + 正文 3 页。建议讲解 4—5 分钟。

## 封面｜培训小慧：从培训需求到可验收物料

- 定位：HR 数字员工体系中的培训子 Agent
- 副标题：ADDIE 流水线驱动的培训物料生成
- 核心原则：业务方定范围，脚本保流程，讲师做终审

## 第 1 页｜业务需求与能力边界

### 业务痛点

- 企业培训不是只制作一份 PPT，还包括需求、课程、讲师与学员材料、测试、实施和评估
- 多份材料分别生成容易口径分叉，测试题也可能与培训目标脱节
- 用户可能只需要部分物料，不应每次默认生成全套
- 缺少真实素材时不能编造制度、数字和名称

### 培训小慧的职责

- 基于 `source-docs/` 真实素材，按用户点名生成 Markdown 培训物料
- 完整能力上限为 8 类物料，但点名几份就生成几份
- 不负责现场组织、自动效果追踪和终稿发布
- 所有结果均为 AI 辅助草稿，须经 HR 与讲师审核

### 页面视觉

左侧“培训业务链”，右侧“负责 / 不负责”边界。

## 第 2 页｜ADDIE Skill 与脚本实现

### ADDIE 五阶段

- A 分析：需求分析
- D 设计：课程设计
- D 开发：PPT 大纲、讲师手册、学员手册、测试题
- I 实施：交付指南
- E 评估：评估反馈表

### 核心实现

- 入口：`training-run.sh generate --theme <主题> [--only ...]`
- `generate_pack.py` 拆分为 7 次阶段调用，逐步读取上游并落盘
- PPT 大纲是讲师手册和学员手册的单一内容源
- 测试题对应需求分析中的 T1—T5 培训目标
- 支持 `--only` 按需生成、断点续跑和 `--force` 重生成
- 讲师手册只生成讲解要点、互动和控场提示，不生成长篇逐字稿

### 页面视觉

使用一条文件依赖流水线，突出“前阶段输出 = 后阶段输入”。

## 第 3 页｜质量门、演示证据与价值

### 交付质量门

- 空素材直接退出，不凭空生成
- 每份文件带“AI 辅助生成、讲师审核后交付”
- `self_check.py` 检查文件、T1—T5、目标矩阵、题目覆盖和 AI 标识
- `eval-cases.md` 人工核验阶段顺序、阶段承接和单一内容源
- 只有 `RESULT: success` 且自检通过，才能汇报完成

### 现场演示

1. 展示真实素材
2. 用户只要求学员手册和测试题
3. 执行 `--only 05,06`
4. 验证只处理点名物料
5. 展示 T1—T5、AI 标识、自检退出码和 `RESULT`

### 总结

培训小慧不是简单的长文生成器，而是一条可按需、可追溯、可验收的培训物料流水线：业务方决定生成范围，脚本保证流程与结构，讲师保留最终审核权。
