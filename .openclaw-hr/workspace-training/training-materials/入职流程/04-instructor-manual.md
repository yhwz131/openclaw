# 入职流程培训 · 讲师手册

## 讲师使用说明
本手册是《入职流程培训》PPT配套的讲师指引，旨在帮助您高效、结构化地完成授课。手册提供了每页PPT的讲解要点、互动建议与控场提示，**本手册不是讲解稿**。请根据现场情况灵活发挥，重点在于传递核心信息并引导学员参与。

## 课前准备清单
1.  **设备与材料**：确认投影、翻页笔、麦克风正常；打印本手册及《新员工资源地图》备用。
2.  **环境与签到**：提前到达场地，检查桌椅布局；准备好电子签到表或纸质签到单。
3.  **内容预热**：回顾本手册各模块要点，特别是【讲师提示】中标记的重点与易超时页面。
4.  **互动准备**：思考如何根据【互动引导】设计开场与过渡问题。

---

### 逐页讲解指引

#### **第1页：欢迎加入某某公司！**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  热情欢迎所有新同事加入某某公司。
    2.  简要介绍自己（姓名、部门、角色）及今日培训主题。
    3.  点明培训目标：帮助大家顺利融入，为高效工作打下基础。
    4.  展示公司标识，营造归属感。
- **互动引导**：可以邀请1-2位学员简单介绍自己（姓名、部门），快速破冰。
- **讲师提示**：用饱满的情绪开场，奠定积极基调。注意控制开场时间，快速进入下一环节。

#### **第2页：培训目标：今天你将掌握什么？**
- **讲解时长**：2分钟
- **讲解要点**：
    1.  清晰读出五个培训目标（T1-T5），强调这是今天培训结束后大家应达到的状态。
    2.  将目标与学员的实际需求（如“报到顺利”、“知道找谁帮忙”）相联系。
    3.  提示这些目标也涵盖了大家在试用期内需要了解和运用的核心知识。
- **互动引导**：“大家看一下这五个目标，有没有哪个是你特别关心或者希望深入了解的？”
- **讲师提示**：本页是建立学习预期的关键，讲解要清晰有力。可以将目标板书在白板或强调PPT上的重点。

#### **第3页：今日培训议程**
- **讲解时长**：2分钟
- **讲解要点**：
    1.  概述全天培训的七大模块，说明逻辑顺序（从准备到支持）。
    2.  说明每个模块的大致时长，让学员对一天的时间安排有整体把握。
    3.  强调模块七是集中答疑，鼓励学员在过程中记录问题。
- **互动引导**：“看完这个议程，大家对哪个模块最期待或者觉得最需要？”
- **讲师提示**：快速过即可，让学员心中有数。提醒大家如有紧急事务需短暂离开，请尽量安排在模块过渡时。

#### **第4页：模块一：入职准备与材料清单（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块一的主题：帮助大家从容报到。
    2.  说明本模块目标：掌握报到必备知识，规避常见问题。
    3.  引出痛点：解决报到前可能存在的“材料准备迷茫”。
- **互动引导**：“在正式报到前，大家对于准备材料是否有过担心或疑问？”
- **讲师提示**：过渡页要简洁，明确模块起点，将学员注意力聚焦到报到准备上。

#### **第5页：必交材料清单详解**
- **讲解时长**：4分钟
- **讲解要点**：
    1.  逐项讲解六类必须材料（身份证、学历证明、离职证明等），强调“原件及复印件”。
    2.  点明体检报告需符合公司具体要求（可提示参考《资源地图》中的指引）。
    3.  解释银行卡信息用于工资发放，确保证件照规格符合要求。
    4.  **强调**：所有材料务必真实、有效。
- **互动引导**：“请大家对照检查一下，自己准备的材料是否齐全，有没有不确定的地方？”
- **讲师提示**：这是实用信息页，讲解需细致。可以放慢速度，确认学员跟上。避免快速跳过。

#### **第6页：重要合规原则与报到日流程**
- **讲解时长**：3分钟
- **讲解要点**：
    1.  用严肃语气强调两条公司红线：不扣押证件、不收取财物。说明这是法律和公司制度底线。
    2.  清晰介绍报到日三个主要步骤：HR办手续、领用品、参加培训。
    3.  告知学员遇到问题的现场求助方式（找引导的HR同事）。
- **互动引导**：“这两条红线体现了公司对员工的哪些基本保障？”
- **讲师提示**：讲解红线时需格外郑重，确保学员理解其严肃性。报到流程可一笔带过，重点在原则。

#### **第7页：模块二：欢迎与公司概览（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块二主题：认识你的新家——某某公司。
    2.  说明目标：建立对公司文化、战略与架构的初步认知。
    3.  引出痛点：解决新员工常见的“信息获取分散”问题。
- **互动引导**：“在加入之前，你对某某公司有哪些初步印象或了解？”
- **讲师提示**：语气回转为欢迎和介绍性质，引领学员进入了解公司的环节。

#### **第8页：使命、愿景与价值观**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  依次讲解使命、愿景的内涵，并结合公司实际业务（如“用科技提升协同与洞察效率”）举例。
    2.  重点解读3-5条核心价值观，每一条用一个简单的行为示例说明其在工作中的体现。
    3.  鼓励学员思考这些价值观如何指导自己的日常工作决策。
- **互动引导**：“这三条价值观中，你觉得哪一条对你未来的工作最有指导意义？为什么？”
- **讲师提示**：本页内容较抽象，需结合实例讲解。时间可能较长，注意精简语言，突出核心价值。

#### **第9页：组织架构与核心业务**
- **讲解时长**：7分钟
- **讲解要点**：
    1.  展示五大组织中心，并简要说明其核心职责（如研发中心负责产品技术实现）。
    2.  利用协作关系图，说明各中心如何相互配合支撑公司运营。
    3.  介绍公司核心产品“协同云”与“数据洞察”，说明其为客户解决的核心问题。
    4.  将公司业务与员工自身岗位的潜在关联点做简单提示。
- **互动引导**：“了解到公司的主要产品后，你认为你的工作可能在哪个环节为产品或客户提供价值？”
- **讲师提示**：架构和业务信息量大，讲解需结构化。可借助图示，避免陷入细节描述。

#### **第10页：模块三：核心制度与合规必修（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块三主题：知规守矩，行稳致远。
    2.  说明目标：理解关键人事与合规制度，保障公司与个人双方权益。
    3.  引出痛点：解决对“制度合规认知不足”的问题。
- **互动引导**：“提到公司制度，你最关心的是哪些方面？（如考勤、薪酬、发展）”
- **讲师提示**：语调转为正式、严谨，预示本模块内容的重要性。

#### **第11页：劳动合同与试用期说明**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  说明劳动合同应在入职一个月内签订，介绍其基本构成。
    2.  详细解读合同期限、试用期时长、薪酬结构等关键条款，强调以合同为准。
    3.  概述试用期录用条件与考核标准，让学员明确预期。
    4.  介绍转正流程的关键节点和时间点，做到心中有数。
- **互动引导**：“关于试用期，大家还有什么具体疑问吗？”
- **讲师提示**：本页内容敏感且重要，务必准确、清晰地传达信息。可以适当放慢节奏，确保学员理解。**建议时长可在此模块适当延长**。

#### **第12页：保密协议与员工手册核心条款**
- **讲解时长**：7分钟
- **讲解要点**：
    1.  强调签署保密协议的必要性，点明其约束的主要范围（商业秘密、技术信息等）。
    2.  介绍员工手册中的几条行为规范红线，如诚信、避免利益冲突。
    3.  告知考勤、休假、报销等日常制度的查询入口（引导至《资源地图》）。
    4.  强调所有制度以最新官方文件为准，鼓励大家主动学习。
- **互动引导**：“你认为保密协议主要保护公司的哪些核心资产？”
- **讲师提示**：重点讲原则和入口，避免逐条宣读手册。突出“红线”和“合规”意识。

#### **第13页：职业发展双通道**
- **讲解时长**：5分钟
- **讲解要点**：
    1.  介绍公司P（专业）序列与M（管理）序列并行的职业发展体系。
    2.  简要说明两个通道的典型发展路径和能力侧重点差异。
    3.  概述内部转岗的基本原则和一般流程。
    4.  给出早期发展建议：专注于能力提升和创造价值，通道选择可后置。
- **互动引导**：“在职业生涯初期，你认为是先深耕专业，还是尝试管理更重要？”
- **讲师提示**：传递公司为员工提供多元发展路径的积极信号，减轻新员工的路径焦虑。

#### **第14页：模块四：IT系统与办公环境实操（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块四主题：工欲善其事，必先利其器。
    2.  说明目标：掌握核心办公工具，顺利开展工作。
    3.  引出痛点：解决IT工具不会用、不敢用的问题。
- **互动引导**：“你最希望先熟练使用公司的哪个IT工具？”
- **讲师提示**：语气转为实用、指导性质，预告本模块将有实操内容。

#### **第15页：企业微信与内部沟通**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  说明企业微信是主要办公沟通工具，介绍下载、登录及核心功能（通讯录、群聊、应用）。
    2.  演示或说明如何查找、添加同事。
    3.  强调内部沟通规范：重要事项留痕、合理建群、尊重他人时间（如下班后非紧急不发消息）。
    4.  指引常用内部应用（会议、文档、审批）的入口位置。
- **互动引导**：“相比于个人微信，你认为使用企业微信进行工作沟通有什么好处或需要注意的地方？”
- **讲师提示**：可结合现场演示。重点讲解沟通规范，这是企业文化的一部分。

#### **第16页：核心IT系统开通与登录**
- **讲解时长**：10分钟
- **讲解要点**：
    1.  分步骤说明公司邮箱、OA系统的配置登录方法。
    2.  重点介绍业务系统（协同云、数据洞察）的账号开通流程与首次登录注意事项。
    3.  清晰告知遇到技术问题时的求助渠道（IT服务台电话/在线工单）。
- **互动引导**：“在首次登录这些系统时，你最担心遇到什么问题？”
- **讲师提示**：信息密集，讲解需有条理。可将步骤要点提前板书或打印发放。**本页易超时，需严格控制每个系统讲解在2-3分钟内**。

#### **第17页：HR数字员工「小慧」使用演示**
- **讲解时长**：7分钟
- **讲解要点**：
    1.  介绍「小慧」的入口（企业微信工作台）。
    2.  现场演示1-2个核心功能（如查询假期余额）。
    3.  教授有效提问技巧：使用关键词，如“年假还剩几天”。
    4.  说明当「小慧」无法解答时，如何转接人工服务。
- **互动引导**：“现在，大家可以想一个你最想通过「小慧」查询的问题。”
- **讲师提示**：**强烈建议进行现场演示**，效果远优于单纯讲解。演示时操作缓慢清晰。

#### **第18页：模块五：人力资源服务与支持网络（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块五主题：你的后盾与向导。
    2.  说明目标：明确各类人事问题的对应解决路径。
    3.  引出痛点：解决“关键接口人不清”的问题。
- **互动引导**：“入职后，如果遇到人事相关问题，你第一时间会想到找谁？”
- **讲师提示**：引导学员关注“支持系统”，为后续内容铺垫。

#### **第19页：HR部门模块与对接事项**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  清晰介绍HR四个组（招聘、人事薪酬、OD&T、员工关系）的核心职责。
    2.  将各组职责与学员可能遇到的具体事项挂钩（如社保找人事薪酬组）。
    3.  强调“找对人”的重要性，可以提高效率。
- **互动引导**：“如果你对培训报名有疑问，应该联系HR的哪个组？”
- **讲师提示**：职责划分可能需要重复强调，确保学员建立基本概念。避免陷入组织架构细节。

#### **第20页：高效提问与导师（Mentor）制度**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  传授高效提问四步法：先用「小慧」→描述清楚背景→明确诉求→找对部门。
    2.  通过1-2个场景（如社保查询）模拟提问过程。
    3.  详解导师制度：导师的角色、职责（业务、文化、答疑）。
    4.  给出与导师沟通的建议频率和初次破冰方法。
- **互动引导**：“你会如何向你的导师介绍你自己和你的第一个问题？”
- **讲师提示**：本页内容极具实用性。场景模拟部分可邀请学员参与，增强互动。

#### **第21页：模块六：融入节奏与试用期展望（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块六主题：规划你的成长里程碑。
    2.  说明目标：建立从入职到转正的阶段性预期。
    3.  引出痛点：解决对“培训与带教预期模糊”的担忧。
- **互动引导**：“对于接下来三个月的工作与学习，你有什么样的初步规划或期待？”
- **讲师提示**：引导学员进入规划视角，思考个人成长路径。

#### **第22页：入职关键阶段任务**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  清晰划分并讲解入职首周、首月、前三月三个阶段的核心任务。
    2.  强调每个阶段的学习重点（如首周熟悉，首月参与，前三月独立）。
    3.  给出每个阶段可操作的行动建议（如“第一周主动约导师午餐”）。
- **互动引导**：“你认为在入职首周，哪项任务对你快速融入最重要？”
- **讲师提示**：将抽象的时间线转化为具体的任务清单，帮助学员建立 actionable 的预期。

#### **第23页：试用期考核与转正**
- **讲解时长**：7分钟
- **讲解要点**：
    1.  说明试用期考核的通常发起时间（结束前1-2个月）。
    2.  阐述考核的主要维度：工作成果、文化契合度、团队协作等。
    3.  简要介绍转正评估可能的形式（如答辩、述职）。
    4.  展望转正后可能的变化（如福利、绩效参与度），给出积极预期。
- **互动引导**：“你认为公司会最看重试用期内的哪些表现？”
- **讲师提示**：传递“考核是双向评估”的积极信号，减轻学员的考核焦虑。强调过程重于结果。

#### **第24页：模块七：答疑与资源导航（过渡页）**
- **讲解时长**：1分钟
- **讲解要点**：
    1.  点明模块七主题：扫清最后障碍，带上你的资源地图。
    2.  说明目标：解答个性问题，获取持续支持的关键路径。
    3.  指出这是综合性解决问题的环节。
- **互动引导**：“经过一天的学习，你还有哪些悬而未决的问题？”
- **讲师提示**：营造开放、安全的提问氛围，鼓励学员提出任何问题。

#### **第25页：开放式Q&A**
- **讲解时长**：10分钟
- **讲解要点**：
    1.  鼓励学员基于全天内容提出问题。
    2.  认真倾听，并尽力回答或引导至正确的资源。
    3.  对于未能当场解决或需后续跟进的问题，记录在白板或共享文档中。
- **互动引导**：“现在开始我们的集中答疑时间，请大家畅所欲言。”
- **讲师提示**：**本环节时间弹性大**，需灵活控场。若冷场，可抛出常见预备问题。记录未解问题承诺跟进。

#### **第26页：《新员工资源地图》发布**
- **讲解时长**：8分钟
- **讲解要点**：
    1.  重点介绍《新员工资源地图》的构成：关键文档、联系人、常用流程入口、学习平台。
    2.  演示或说明如何获取和访问该资源地图。
