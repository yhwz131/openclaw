# 入职流程培训 · 课后测试题

**试卷说明**
- 题型与数量：6 道单选、2 道多选、2 道简答，共 10 题。
- 难度梯度：基础 / 中等 / 应用三档。
- 覆盖范围：入职材料与合规、公司概览与组织架构、HR数字员工「小慧」使用、入职到转正关键节点、双通道职级体系与内部转岗。
- 建议用途：培训后即时测评，也可作为学员复习工具。建议讲师在公布答案前，先组织学员对错题进行讨论。

## 一、单选题（每题仅有一个正确答案）

**1. 【基础】【对应培训目标T1】** 报到当天，以下哪项做法符合某某公司的入职材料与合规要求？

A. 为方便归档，将身份证原件交由HR长期保管  
B. 带齐身份证、学历学位证书、离职证明、体检报告等必备材料，公司不扣押证件原件、不收取财物  
C. 先不携带离职证明，等试用期结束再补交即可  
D. 因公司收取工牌押金，可先不准备银行卡信息  

**答案：B**

**答案详解：**
- B 正确：手册明确列出报到当天需带齐身份证、最高学历学位证书、离职证明、体检报告、银行卡信息、证件照等必备材料，并强调公司绝不扣押证件原件、绝不收取财物作为入职条件。
- A 错误：公司绝不以任何理由扣押证件原件，交由HR长期保管不符合合规原则。
- C 错误：材料不全时，应第一时间联系对接的招聘HR同事说明情况、协商解决方案，而不是默认可以试用期后补交。
- D 错误：公司绝不向新员工收取财物作为入职条件；银行卡信息用于工资发放，属于应准备的信息。

**2. 【基础】【对应培训目标T2】** 以下哪一组完整列出了某某公司的五大组织中心？

A. 研发中心、产品中心、商业化中心、职能支持中心、战略中心  
B. 研发中心、产品中心、商业化中心、职能支持中心  
C. 研发中心、产品中心、商业化中心、战略中心、市场中心  
D. 产品中心、商业化中心、职能支持中心、战略中心、客户成功中心  

**答案：A**

**答案详解：**
- A 正确：手册写明公司主要由研发中心、产品中心、商业化中心、职能支持中心、战略中心五大组织中心构成。
- B 错误：缺少“战略中心”，属于范围缩小。
- C 错误：将“职能支持中心”替换为“市场中心”，属于概念混淆。
- D 错误：缺少“研发中心”，并将“研发中心”替换为“客户成功中心”，同样不符合手册表述。

**3. 【中等】【对应培训目标T3】** 新员工使用HR数字员工「小慧」查询政策，当「小慧」无法解答时，最恰当的做法是？

A. 继续用相同关键词反复提问，直到「小慧」给出答案  
B. 放弃查询，等试用期结束再问  
C. 根据「小慧」引导转接人工服务，并清晰描述问题背景与诉求，找到对应HR模块  
D. 直接在企业微信全员群发消息，@所有人询问  

**答案：C**

**答案详解：**
- C 正确：手册建议的路径是：先尝试用「小慧」查询 → 若需人工，清晰描述问题背景与诉求 → 找到正确的负责部门。若「小慧」无法解答，它会引导转接人工服务。
- A 错误：重复用相同关键词提问，不能解决超出「小慧」知识范围的问题，反而浪费时间。
- B 错误：延迟处理可能影响入职手续或政策理解，不符合“遇到问题及时解决”的入职节奏。
- D 错误：全员群发会打扰他人，也不一定能找到对口的HR模块，不符合高效提问原则。

**4. 【中等】【对应培训目标T4】** 关于试用期转正评估的启动时间，以下说法正确的是？

A. 试用期结束后一个月才启动  
B. 试用期结束前一周启动  
C. 试用期结束前1-2个月启动  
D. 入职满三个月时自动启动，与试用期截止时间无关  

**答案：C**

**答案详解：**
- C 正确：手册写明，试用期结束前1-2个月，会启动转正评估。
- A 错误：把时间调到试用期结束后一个月，与手册表述不符。
- B 错误：把“1-2个月”缩短为“一周”，时间范围被严重压缩。
- D 错误：转正评估与试用期节点直接相关，并非与试用期截止时间无关；同时“自动启动”忽略与上级、HR的沟通确认环节。

**5. 【中等】【对应培训目标T5】** 关于某某公司职业发展双通道与内部转岗，以下理解正确的是？

A. 专业通道（P序列）是管理岗，管理通道（M序列）是专业岗  
B. 员工一旦选择P序列，就永远不能转岗到M序列或内部其他岗位  
C. 公司设有专业通道（P序列）和管理通道（M序列），均强调持续提升专业能力、创造价值，并支持内部转岗，具体政策可咨询HR  
D. 只有管理通道有发展空间，专业通道只是过渡  

**答案：C**

**答案详解：**
- C 正确：手册明确公司设置专业通道（P序列）和管理通道（M序列），两条通道均有广阔发展空间，核心是持续提升专业能力、创造价值；公司支持内部转岗，具体政策可咨询HR。
- A 错误：把P序列和管理岗、M序列和专业岗的概念相互颠倒。
- B 错误：将“支持内部转岗”曲解为“永远不能转岗”，属于绝对化错误。
- D 错误：手册明确两条通道均有广阔发展空间，专业通道并非过渡。

**6. 【应用】【对应培训目标T2】** 新员工小王需要报名公司级培训，同时他的OA系统无法登录。根据“遇到问题找对接口人”的原则，他应优先分别联系谁？

A. 培训报名找OD&T组，系统登录问题找IT服务台  
B. 培训报名找招聘组，系统登录问题找人事薪酬组  
C. 培训报名找员工关系组，系统登录问题找行政前台  
D. 培训报名找战略中心，系统登录问题找商业化中心  

**答案：A**

**答案详解：**
- A 正确：手册中OD&T组负责培训报名、职业发展咨询、Mentor事宜；IT服务台负责处理系统登录等问题。
- B 错误：招聘组主要负责入职前事宜、转岗咨询；人事薪酬组负责劳动合同、社保公积金、薪酬发放、日常人事手续，两者都不是培训报名和系统登录的首选接口。
- C 错误：员工关系组负责文化活动、员工关怀；行政前台不负责系统权限或登录问题。
- D 错误：战略中心、商业化中心是业务组织中心，不承担此类HR或IT支持接口职能。

## 二、多选题（每题有两个或两个以上正确答案，多选、少选、错选均不得分）

**7. 【中等】【对应培训目标T1】** 关于入职材料准备与合规原则，以下说法正确的有？

A. 报到当天需携带身份证、最高学历学位证书、离职证明、体检报告等必备材料  
B. 公司绝不以任何理由扣押新员工证件原件  
C. 公司绝不向新员工收取任何财物作为入职条件  
D. 如果材料不全，可以直接忽略，等HR日后自行发现  

**答案：ABC**

**答案详解：**
- A 正确：手册列出报到当天需带齐的必备材料，包括身份证、最高学历学位证书、离职证明、体检报告、银行卡信息、证件照等。
- B 正确：公司绝不以任何理由扣押证件原件，这是重要合规原则。
- C 正确：公司绝不向新员工收取任何财物作为入职条件，同样是重要合规原则。
- D 错误：材料不全时应第一时间联系对接的招聘HR同事，说明情况并协商解决方案，不能忽略或等待HR自行发现。

**8. 【应用】【对应培训目标T3】** 当新员工遇到一个HR政策问题时，以下哪些做法符合“高效提问”的路径？

A. 先尝试通过「小慧」查询，使用关键词提问  
B. 若「小慧」无法解答，清晰描述问题背景与诉求，并找到正确的负责部门  
C. 同时向所有HR模块群发相同问题，催促尽快回复  
D. 向导师请教融入团队、工作困惑相关的问题，同时保留HR渠道处理正式人事政策  

**答案：ABD**

**答案详解：**
- A 正确：手册建议先尝试用「小慧」查询，提问时尽量使用关键词。
- B 正确：若「小慧」无法解答，应清晰描述问题背景与诉求，并找到正确的负责部门，这是高效提问路径。
- C 错误：同时向所有HR模块群发相同问题，会增加沟通成本、扰乱接口分工，不符合高效提问原则。
- D 正确：导师是融入团队、解决工作困惑的重要引导人，职责包括业务指导、文化融入和答疑解惑；但正式人事政策仍应找对应HR模块，因此该表述合理。

## 三、简答题

**9. 【应用】【对应培训目标T4】** 请简述新员工从入职到转正的关键流程节点，并说明每个阶段需要配合的主要事项。

**参考答案：**
- 入职首周：熟悉环境、认识同事、完成基础IT设置、与导师建立首次联系。
- 入职首月：参加部门级培训，了解团队目标与当前项目，开始承担基础工作任务。
- 入职前三月：独立完成常规工作，理解业务逻辑，初步建立内部协作网络。
- 试用期结束前1-2个月：启动转正评估；配合直属上级和HR确认评估标准，准备评估相关材料。
- 转正评估：综合考量岗位职责履行情况、工作成果、文化价值观契合度及团队协作；通过评估后转正，享受完整福利并全面参与绩效管理。

**评分要点（总分10分）：**
- 答出“入职首周、入职首月、入职前三月”三个节点，各1分，共3分。
- 答出“试用期结束前1-2个月启动转正评估”，2分。
- 答出各阶段配合事项，如与导师联系、参加部门培训、承担基础任务、准备评估等，2分。
- 答出转正评估的综合维度，或转正后的变化，2分。
- 语言清晰、流程顺序正确，1分。

**10. 【应用】【对应培训目标T5】** 请解释某某公司双通道职级体系（专业通道P/管理通道M）及内部转岗的基本原则，并给新员工早期职业发展提出两条建议。

**参考答案：**
- 公司设置专业通道（P序列）和管理通道（M序列）两条职业发展路径，两条通道均有广阔发展空间。
- 核心原则是持续提升专业能力、创造价值；职业发展不依赖单一通道，公司支持内部转岗，具体政策可咨询HR。
- 早期建议：聚焦能力提升和工作价值创造；主动与导师、上级沟通，了解P序列和M序列的能力要求，为长期发展打下基础。

**评分要点（总分10分）：**
- 正确写出专业通道P、管理通道M，2分。
- 说明两条通道均有发展空间，或核心在持续提升专业能力、创造价值，2分。
- 说明公司支持内部转岗、具体政策可咨询HR，2分。
- 给出两条早期职业发展建议，每条1分，共2分。
- 表达清晰、结合新员工场景，1分。
- 整体逻辑与手册一致，1分。
