# 某某公司 · 后端开发工程师（JD 草稿）

> 说明：本文件为后端开发岗位 JD 草稿，用于人才库语义检索与筛选排序。

## 岗位职责

1. 负责公司核心业务系统的后端设计、开发与维护，独立完成模块级方案设计与编码落地；
2. 参与微服务架构的服务拆分、接口设计与性能优化，保障系统高并发、高可用；
3. 负责 MySQL 等数据库的表结构设计与 SQL 调优，合理使用 Redis 等缓存组件；
4. 参与代码评审、技术文档编写与线上问题排查，持续改进系统可观测性与稳定性；
5. 与产品、前端、测试紧密协作，按迭代计划交付高质量功能。

## 任职要求

1. 本科及以上学历，计算机相关专业，3 年以上后端开发工作经验；
2. 精通 Java 或 Go 至少一门后端语言，熟悉 Spring Boot / Spring Cloud 或同类微服务框架；
3. 熟悉 MySQL、Redis，理解索引优化、事务与缓存一致性设计；了解消息队列（Kafka/RabbitMQ/RocketMQ）；
4. 熟悉 Linux 开发环境，具备分布式系统、高并发场景的开发或调优经验；
5. 熟悉常见设计模式与微服务治理（服务注册发现、熔断限流、链路追踪），了解容器化部署（Docker/K8s）者优先；
6. 具备良好的编码习惯、问题分析与沟通协作能力，能独立承担模块并推动落地。

## 加分项

- 有大型互联网或高流量系统的性能优化经验；
- 有开源项目贡献或技术博客输出；
- 有团队技术分享、带新人经验。
