# 某某公司 · 数据分析师（JD 草稿）

> 说明：本文件为数据分析师岗位 JD 草稿，用于候选人评分对照与排序。岗位为候选人求职意向导出，非现成样本库条目。

## 岗位职责

1. 负责用户增长、留存与经营分析，输出可支撑业务决策的数据结论与看板；
2. 负责搭建与维护核心业务指标体系（转化、留存、复购等），定位关键环节的问题与机会；
3. 设计并评估 A/B 实验，沉淀实验流程与评估模板，推动实验结论快速落地；
4. 使用 SQL / Python 完成数据提取、清洗与分析，与产品、运营、市场团队协作复盘；
5. 负责用户分层与精细化运营的数据支持（如 RFM 分群、定向触达效果评估）。

## 任职要求

1. 本科及以上学历，统计学、数据科学、计算机等相关专业，3 年以上互联网数据分析经验；
2. 熟练使用 SQL，能用 Python（pandas / numpy）完成数据处理与分析；
3. 熟悉常用分析工具（Excel、Tableau、Power BI 等），能独立搭建业务看板；
4. 熟悉 Hive / ClickHouse 等数据仓库，了解埋点设计与数据校验；
5. 掌握 A/B 实验、漏斗与留存分析、RFM 分层等分析方法，能把业务问题拆解为可量化指标；
6. 具备良好的沟通与跨团队协作能力，能独立承担分析专题并推动落地。

## 加分项

- 有用户增长或经营分析的完整闭环经验；
- 有数据调度与工程化能力（如 Airflow 调度）；
- 有面向多条业务线提供分析支持的经验。
