# 后端开发工程师（JD 草稿）

## 岗位职责

1. 负责公司业务系统后端服务的设计、开发与维护，保障服务稳定、可扩展。
2. 参与接口设计、数据库设计与系统性能优化，支撑高并发业务场景。
3. 编写高质量、可维护的代码，参与代码评审，完善单元测试与技术文档。
4. 与前端、产品、测试协作，按时高质量交付需求。
5. 排查线上问题，持续优化系统性能与工程质量。

## 任职要求

1. 计算机相关专业本科及以上学历。
2. 熟练掌握至少一门后端开发语言（Java / Go / Python / C++ 等），理解常用数据结构与算法。
3. 熟悉 MySQL / PostgreSQL 等关系型数据库及 Redis 等常用中间件，具备数据库设计与调优经验。
4. 熟悉 Spring Boot / 微服务 / 分布式系统相关技术，具备高并发、高可用系统开发经验者优先。
5. 熟悉 Linux 开发环境，掌握 Git，了解 CI/CD 与容器化技术者优先。
6. 具备良好的沟通协作能力与责任心，有较强的学习能力和问题分析能力。

## 加分项

- 有开源项目贡献或技术博客。
- 有大规模分布式系统、消息队列（Kafka / RabbitMQ）实践经验。
